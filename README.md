# Swag-Labs-Manual-Testing-Training
Manual QA project on the Swag Labs demo site  (https://www.saucedemo.com) including acceptance criteria, test cases, test evidence and bug reports

# NOTE:
This project was created as part of a training program based on requirements provided by the academy.
The project follows the academy's requirements and is not fully complete.
During testing, i observed additional considerations (missing validations for username and password length and other edge cases.
These observations were noted but not added in the official project documents.

# Project Workflow
* Acceptance criteria : Defines the expected behavior for site features
* Test Cases: Manual scenarios derived from the acceptance criteria
* Test evidence (screenshots and notes)
* Bug reports
